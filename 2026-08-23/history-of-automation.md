## トップ5

### 1. Automating and Scaling Behavioral Scientific Research on AI Agents
- 出典: arXiv
- 日付: 2026-08-10投稿、2026-08-15改訂
- リンク: https://arxiv.org/abs/2608.10030
- 要約: AEROBATというマルチエージェントシステムが、AIエージェントの行動に関する仮説生成、実験設計、シミュレーション実行、統計分析、レポート作成までを自動化する研究。12の対象行動について73仮説、1,160実験、22,954シミュレーションを実行し、AIエージェント研究そのものを自動化対象にしている。
- なぜ面白いか:
  - 技術: 自動化の対象が「作業」から「実験計画と知識生産のワークフロー」へ拡張され、AIエージェントを研究するためのエージェント化された実験室が見えてきた。
  - 人文: これはテイラー主義的な労働分解の最新版であると同時に、科学者の判断・解釈・懐疑をどこに残すかという制度設計の問題でもある。労働史的には、工場の作業測定がホワイトカラーと研究労働へ移動した例として読める。

### 2. The Capability Ladder: A Curriculum-Modernization Framework for Workforce Readiness in the AI Era
- 出典: arXiv
- 日付: 2026-08-07（直近約14日より少し前だが重要）
- リンク: https://arxiv.org/abs/2608.07779
- 要約: AI時代の教育・職能を「trigger / automation / workflow / AI agent / agent team」という5段階のCapability Ladderで整理するカリキュラム論文。近未来の変化は完全代替ではなく、実装作業の自動化と、検証・システム思考・セキュリティ・AI監督能力の価値上昇だと位置づける。
- なぜ面白いか:
  - 技術: エージェントの自律度と人間の監督要件を段階化し、教育課程や職務設計に接続できる操作的なモデルを提示している。
  - 人文: 自動化の歴史では、機械化のたびに「熟練」が消えるのではなく再定義されてきた。この論文は、AIエージェント時代の熟練を「手を動かす能力」から「監督し、検証し、チーム化する能力」へ翻訳している点が面白い。

### 3. Anthropic Economic Index
- 出典: Anthropic公式Web
- 日付: 2026-06-26最終更新（古いが、現在の議論の基盤として重要）
- リンク: https://www.anthropic.com/economic-index
- 要約: Claudeの利用データをもとに、地域・職業・タスクごとのAI利用を可視化する継続的な経済インデックス。公式説明では、人々がAIを仕事の「augment（協働・能力拡張）」として使うのか「automate（委任・自動化）」として使うのかを追跡することが中心テーマになっている。
- なぜ面白いか:
  - 技術: LLM利用ログを職業・タスク分類と接続し、AIエージェント化が実際の労働プロセスでどこまで委任に近づいているかを観測するデータ基盤になっている。
  - 人文: 自動化史で繰り返された「補助か代替か」という対立を、会話ログ由来の実証データで再測定しようとしている。労働政策や教育政策が逸話ではなく、実際の利用パターンをもとに議論される可能性を開く。

### 4. The 2026 AI Index Report
- 出典: Stanford HAI公式Web
- 日付: 2026年版（公開ページ確認）
- リンク: https://hai.stanford.edu/ai-index/2026-ai-index-report
- 要約: 2026年版AI Indexは、AIエージェントがOSWorldのような実コンピュータ操作ベンチマークで約12%から約66%のタスク成功率へ飛躍した一方、構造化ベンチマークではなお約3回に1回失敗すると説明している。AIの能力は「できること」と「失敗すること」がまだらに分布する、いわゆるjagged frontierとして描かれている。
- なぜ面白いか:
  - 技術: エージェントの実作業能力を、チャット応答ではなくOS操作・タスク遂行という自動化史に近い尺度で測っている。
  - 人文: 産業用ロボットや事務自動化と同じく、導入判断は平均性能ではなく失敗時の責任・監査・復旧制度に左右される。AIエージェントの「3回に1回失敗」は、労働者を置き換える物語よりも、人間の見張り役化という文化的変化を示している。

### 5. LLMs in Process Diagram Engineering: From Optimal PFDs to Validated P&IDs
- 出典: arXiv
- 日付: 2026-07-21（古いが、産業自動化との接続が強いため採用）
- リンク: https://arxiv.org/abs/2608.11220
- 要約: 化学・プロセス工学で手作業が多いPFD（Process Flow Diagram）からP&ID（Piping and Instrumentation Diagram）への変換を、遺伝的アルゴリズムとLLMを組み合わせたAIパイプラインで支援する研究。時間短縮だけでなく、複数トポロジー探索やルール違反検証まで含む。
- なぜ面白いか:
  - 技術: 古典的な産業自動化の中核であるプロセス設計に、LLMが自然言語・設計ルール・探索アルゴリズムの接着剤として入っている。
  - 人文: 自動化の歴史は工場現場から始まったが、ここでは設計図を書く技術者の判断が自動化の対象になる。ブルーカラーの機械化とホワイトカラーのエージェント化が、同じ「工程の形式化」という系譜でつながって見える。
