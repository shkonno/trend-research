### 1. Agent Skills Can Be Harmful: スキルがエージェントを壊す失敗帰属研究
- 出典: arXiv
- 日付: 2026-08-12
- リンク: http://arxiv.org/abs/2608.11888
- 要約: LLMエージェントに読み込ませる「スキル」や手順書が、成功率を上げるだけでなく、機能失敗やコスト増を引き起こすケースを体系的に分析した論文。307件のskill-induced failureを調べ、過剰な検証・重い実装パイプライン・一見関連するが要求を歪めるスキルが問題になると報告しています。
- なぜ面白いか:
  - 技術: 「コンテキストを増やせばよい」ではなく、各スキルの差分効果をno-skill/類似skill実行と比較して失敗を帰属する、実務的なデバッグ視点を提示しています。
  - 人文: これはLLM活用における“教育”の失敗例でもあり、善意のチェックリストが現場の判断を奪う官僚制になる危険を示しています。人間の熟練者が持つ「今回は省く」「軽く済ませる」という裁量の価値が浮き彫りになります。

### 2. The Role Specialization Model: 複数LLMツールを役割分担で使う開発ケーススタディ
- 出典: arXiv
- 日付: 2026-08-12
- リンク: http://arxiv.org/abs/2608.12311
- 要約: Antigravity、Gemini CLI、Qwen Codeを、設計・実装・補助などの役割に分けて協調させるRole Specialization Model（RSM）の探索的ケーススタディ。気候データ可視化アプリ開発を題材に、計画した役割分担からの逸脱、プロンプト強化、コンテキスト管理、人間による検証の必要性を記録しています。
- なぜ面白いか:
  - 技術: 単一の最強エージェントに任せるのではなく、モデル/ツールごとの得意不得意を役割として固定し、逸脱を観察するワークフロー設計が実践的です。
  - 人文: これはAI時代のチーム編成論でもあります。人間が「誰に何を任せ、どこで介入するか」を設計する管理能力が、プロンプト能力と同じくらい重要になっていることを示します。

### 3. MazeRunner: 失敗レビューと手がかり管理で非線形タスクを進めるペンテスト・エージェント
- 出典: arXiv
- 日付: 2026-08-14
- リンク: http://arxiv.org/abs/2608.14216
- 要約: ブラックボックス・ペネトレーションテストを、グローバル統括、文脈集約的な実行、失敗指向レビューの3エージェントに分け、タスク状態と環境証拠を永続管理する研究。Claude Sonnet 4.5を使った評価では、分岐探索・前提回復・長距離の手がかり相関で既存手法を上回ったと報告しています。
- なぜ面白いか:
  - 技術: LLMを一直線の自動化ではなく、失敗・分岐・証拠の再利用を扱う探索システムとして組む点が、複雑な業務ワークフローにも応用しやすいです。
  - 人文: “賢いAI”より“迷子になっても戻れるAI”を重視しているのが興味深いです。人間の調査や創作も、直線的な推論ではなく、寄り道と記録と再解釈の反復で進むことを思い出させます。

### 4. rungraph: Claude Codeなどのエージェント実行履歴をグラフで読む
- 出典: GitHub / Hacker News
- 日付: 2026-08-16（HN掲載）、GitHub更新 2026-08-17
- リンク: https://github.com/fayzan123/rungraph
- 要約: Claude Codeセッションなどのエージェント実行ログを、オーケストレーター、サブエージェント、ツール呼び出し、リトライ、失敗点の有向グラフとして可視化するツール。既存ログを後から読み込め、実行中のセッションもローカルで観察できると説明されています。
- なぜ面白いか:
  - 技術: 「なぜそのEditが失敗し続けたのか」「どのファイルがどの手順で触られたのか」をログ検索ではなく構造として追えるため、検証・監査・チーム共有に向いています。
  - 人文: LLMエージェントの作業はしばしばブラックボックス化しますが、グラフ化は“機械の思考の航跡”を人間が読み直すための記譜法になります。これは説明責任だけでなく、共同制作の記憶術としても重要です。

### 5. awesome-ai-prompts: 「verify, don't guess」を学生開発者向けに型化するプロンプト集
- 出典: GitHub
- 日付: 2026-08-15作成、2026-08-17更新
- リンク: https://github.com/StudentSuite/awesome-ai-prompts
- 要約: Claude、ChatGPT、Copilot、Cursor、opencodeなどのAI coding agentに貼り付けて使う、学生開発者向けのプロンプト集。READMEでは「verify, don't guess」「small steps」「tests as guardrails」を掲げ、機能実装、ペアプログラミング、デバッグなどの用途別プロンプトを提供しています。
- なぜ面白いか:
  - 技術: 初学者向けでありながら、タスク理解、計画、小さな実装、テスト、文書化という検証駆動のループをプロンプトの型として配布している点が実用的です。
  - 人文: これは単なるテンプレ集ではなく、AI時代の“徒弟制”の教材に近いものです。学生がLLMに丸投げするのではなく、良い開発者の作法を会話の形で学ぶ入口になり得ます。
