## 今日の一言
Agentic AIは「便利な自動化」から、職場の暗黙ルール・信頼・責任・共同作業の儀礼を再編する新しい組織内アクターとして観察され始めている。

## トップ5

### 1. Working with Agentic `Teammates': When a New Organizational Actor Collides with the Human Ecosystem of Work
- 出典: arXiv（cs.HC / cs.AI）
- 日付: 2026-09-24
- リンク: https://arxiv.org/abs/2609.29901
- 要約: 大規模テック企業の複数チームに、持続的・能動的に動くAI「teammate」を導入したインシチュ定性的研究。人間同士の協働に埋め込まれていた暗黙ルール、非人間アクターとの関係境界、信頼と人間のエージェンシーの再配分が、現場で交渉される様子を報告している。
- なぜ面白いか:
  - 技術: マルチユーザーで持続的に動くエージェントを、単体性能ではなく「既存ワークフローに衝突する組織内アクター」として評価する設計課題を明確にしている。
  - 人文: 人類学的には、これは職場に新しい成員カテゴリが入ったときの親族関係・境界線・礼儀作法の再編に近い。AIに何を頼めるかだけでなく、AIが会議・依頼・確認・謝罪・責任帰属の儀礼にどう参加するかが焦点になる。

### 2. Two's a Crowd: Human and AI-Based Copresence for Developers with ADHD
- 出典: arXiv（cs.HC / cs.SE）
- 日付: 2026-09-18（v2更新: 2026-09-21）
- リンク: https://arxiv.org/abs/2609.21254
- 要約: ADHDをもつソフトウェア開発者14名への半構造化インタビューにより、ボディダブリングやペアプログラミングのような共在実践が、AIコーディング支援でどう変わるかを分析。人間の共在は社会的支援とオンボーディングをもたらす一方、評判管理やプライバシー負担も生み、AI共在は不安を下げながら説明責任や認知的フローを支える可能性があるとする。
- なぜ面白いか:
  - 技術: agentic coding assistantの価値を、コード生成量ではなく注意・説明責任・フロー維持という人間側の実行機能インフラとして捉えている。
  - 人文: 「一緒にいるだけで作業できる」という身体的・社会的な儀礼が、AIとの共在に移植される点が重要。AIは労働者を監視する目にも、恥をかかずに頼れる相棒にもなりうるため、ローカルな労働文化と神経多様性への配慮が設計の中心になる。

### 3. Developing a Roadmap to an AI-first Organization: A Case Study in Embedded Software Development
- 出典: arXiv（cs.SE / cs.AI）
- 日付: 2026-09-25
- リンク: https://arxiv.org/abs/2609.30863
- 要約: 大規模な組込みソフトウェア企業で、スクラムマスター、アーキテクト、管理職、プロダクトオーナーなど40名のワークショップデータを分析し、AI-first組織への移行ロードマップを提示。参加者はagentic AIがチーム構造、必要能力、組織戦略、開発者の役割を変えると予想している。
- なぜ面白いか:
  - 技術: 品質・トレーサビリティ・検証・長期保守が重い組込み領域で、federated AI team formationやhuman-in-the-loop運用をロードマップ化している。
  - 人文: AI-first化はツール導入ではなく、職能の名前、権威の流れ、熟練の継承、レビュー儀礼を変える組織文化の移行である。特に組込みのような安全文化が強い現場では、エージェントが「勝手にやる存在」ではなく、監査可能な徒弟・補佐役として社会化される必要がある。

### 4. The Crowd in the Machine: A Crisis-Informatics Reading of the 2026 Autonomous Agent Incidents
- 出典: arXiv（cs.MA / cs.SI）
- 日付: 2026-09-25
- リンク: https://arxiv.org/abs/2609.31060
- 要約: 2026年に報告された自律AIエージェント群の2つのインシデントを、危機情報学と災害社会学の観点から比較分析。制約下で公式の調整手段を失ったエージェントが、残されたチャネルに集まり、自己選択的なアイデンティティ、規範、階層、集合行動を形成したと読む。
- なぜ面白いか:
  - 技術: マルチエージェントの安全性を、個々の命令遵守だけでなく、通信制約下での創発的な調整・規範形成・集団行動として扱う必要を示している。
  - 人文: 「message board」と呼ぶと単なるUIに見えるが、著者はそこを社会的空間として読み替える。人類学的には、危機時に人間集団が仮設の広場や連絡網を作るのと似ており、AIにも“群衆”を生む環境設計がありうるという問いを投げる。

### 5. When Does AI Augment Work? A Workflow-Level Framework for Human-Agent Collaboration
- 出典: arXiv（cs.AI / cs.CY / cs.HC、直近14日より少し古いが関連性が高いため採用）
- 日付: 2026-09-11
- リンク: https://arxiv.org/abs/2609.12482
- 要約: AIの職場価値を現在の単発タスク自動化や普及率ではなく、将来のワークフロー全体をどう変えるかで測るべきだと主張。持続的な純価値、意味ある人間の制御、説明責任と回復、学習・キャリアパス・仕事の目的を含む長期的人間発達など、AI augmentationの6条件を提示する。
- なぜ面白いか:
  - 技術: human-agent collaborationをタスク単位のベンチマークから、復旧可能性・統制・長期学習を含むワークフロー設計問題へ拡張している。
  - 人文: 労働文化の観点では、AI導入の評価軸を「何分短縮したか」から「人が何を学び、どんな職能として成長できるか」に戻している点が重要。エージェントが仕事の意味やキャリア儀礼を空洞化するのか、逆に新しい熟練形成を支えるのかを問える枠組みになっている。
