Agentic AIの面白さは、モデル性能そのものよりも、人間のチームが「エージェントに読ませる規則」「隔離された作業場」「委任の作法」を作りはじめた点にある。

## トップ5

### 1. Agentic AIを「行為するAI」として6段階で測る分類法
- 出典: Web記事（Agentic.ai）
- 日付: 2026-10-02更新（記事内メタデータで確認）
- リンク: https://agentic.ai/what-is-agentic-ai
- 要約: Agentic AIを、単に賢く応答するチャットボットではなく、目標に向けて計画し、ツールを呼び、結果を観察してループを回すシステムとして定義している。0-36点・9次元・6レベルというスコアリングで、自律性を二値ではなくスペクトラムとして扱う点が実務的。
- なぜ面白いか:
  - 技術: エージェント性を「ツール実行」「フィードバックループ」「適応」の組み合わせとして測るため、導入時の評価軸に変換しやすい。
  - 人文: 人類学的には、これは新しい「人格」や「役割」の分類体系に近い。職場で誰が判断し、誰が観察し、誰が責任を負うのかを、ソフトウェア分類が再編しつつある。

### 2. AGENTS.mdが「エージェント向けREADME」として広がる
- 出典: 公式サイト / GitHub README（AGENTS.md）
- 日付: 公開日不明（2026-10-02調査時点で確認、公式サイトは「6万以上のOSSプロジェクトで使用」と記載）
- リンク: https://agents.md/
- 要約: AGENTS.mdは、AIコーディングエージェントにプロジェクト固有の文脈、セットアップ、テスト、PR作法を伝えるためのシンプルなオープン形式。READMEは人間向け、AGENTS.mdはエージェント向け、という分業を明確にしている。
- なぜ面白いか:
  - 技術: 複数エージェント／複数ツールに共通する設定面を標準化し、ビルド・テスト・コード規約を実行前コンテキストとして注入できる。
  - 人文: これは組織の「口伝」やオンボーディング儀礼を、機械が読める家訓に変える動きである。チーム文化がREADMEから分岐し、人間向けの物語とエージェント向けの掟に分かれはじめている。

### 3. 日本語圏でのAGENTS.md/CLAUDE.md運用が「現場の作法」として整理される
- 出典: Qiita記事（@dai_chi）
- 日付: 2026-01-20（古いが実務上重要）
- リンク: https://qiita.com/dai_chi/items/61019c602c2c40dade07
- 要約: Claude Code、GitHub Copilot、Codex CLI、Gemini CLIなどの導入現場で、AGENTS.mdやCLAUDE.mdを「プロジェクト固有のコンテキストを伝える設定レイヤー」として使う実践を解説。リファレンス型／指示型、モノレポ運用、コンテキストエンジニアリングまで踏み込んでいる。
- なぜ面白いか:
  - 技術: エージェントの出力品質を、プロンプト単体ではなくリポジトリ内の継続的な設定ファイルで制御する設計に移している。
  - 人文: 日本語の開発現場では「うちのプロジェクトではその書き方をしない」という違和感が、明文化の契機になっている。ローカルな職人規範が、AIに読ませる制度文書へ翻訳されている点が文化人類学的に面白い。

### 4. AGENTS.mdを20以上のAIツールにまたがるポータブル標準として読む
- 出典: Qiita記事（@kai_kou）
- 日付: 2026-03-10公開、2026-06-16更新（古いが実務上重要）
- リンク: https://qiita.com/kai_kou/items/cc9520a24d7c0e38ead4
- 要約: AIコーディングツールが増え、ツールごとに設定を書き直す負担が出たことを背景に、AGENTS.mdをポータブルな設定ファイルとして解説している。CLAUDE.mdとの共存、対応ツール、BuildやArchitecture、Boundariesといった標準項目が整理されている。
- なぜ面白いか:
  - 技術: エージェントの振る舞いをベンダー固有設定から切り離し、ツール横断の運用知として管理する方向を示している。
  - 人文: これは「方言」の乱立から「共通語」への移行であり、同時に各チームが自分たちの境界線を再記述する過程でもある。エージェント時代の組織文化は、使うAIよりも、AIに越えさせない境界の書き方に表れる。

### 5. VS Code Agents windowがエージェント作業の「場」をUI化する
- 出典: AI総合研究所 記事
- 日付: 2026-05-19（古いが実務上重要）
- リンク: https://www.ai-souken.com/article/what-is-vscode-agents-window
- 要約: VS Code 1.120のStable版プレビューとして公開されたAgents windowを、エージェント駆動開発専用の統合UIとして解説。Copilot CLI、Copilot Cloud、Claudeエージェントを切り替え、サブセッションやWorktree isolationで並列作業を管理できると説明している。
- なぜ面白いか:
  - 技術: Worktree isolationを既定にすることで、本流のコードを汚さずエージェント作業を並列化する設計が、開発フローに組み込まれている。
  - 人文: エージェントは抽象的な知能ではなく、「別室」「作業台」「隔離された工房」を必要とする存在としてUIに現れている。身体性の観点では、人間の注意・画面・リポジトリ空間が、AIに仕事を委任するために再配置されている。
